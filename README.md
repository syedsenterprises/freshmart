# FreshMart — Farm Fresh Vegetables & Fruits

Live demo site: a vegetable & fruit store with a working cart.

**What actually works (in your browser, no server needed):**
- Category filters (All / Vegetables / Fruits / Leafy greens)
- Cart with quantities, subtotal, delivery (free over $25, else $3.99), and total
- Cart saved in localStorage — it survives closing the page
- Checkout form that places an order and shows an order reference

**Honest limits:** this is a static front-end. No payment is processed and no
order is sent anywhere. To sell for real, connect a payment provider
(Stripe/PayPal) and a backend or order form service.
